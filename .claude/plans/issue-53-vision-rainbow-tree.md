# /vision 中央の木をレインボー化＋樹冠を極小文字のアスキーアート葉に作り替え — Issue #53

## Context

クライアント要望で中央の木を「多様性（ダイバーシティ）」を象徴する**レインボー（虹色）**にしたい。
あわせて、葉（樹冠）の表現を大きく変更する：現状は「緑のブロブ（葉の塊）＋落下するマトリックスレイン」で
葉を作っているが、これを **エコ語録（`ECO_WORDS`→`MATRIX_GLYPHS`）の極小文字を密に敷き詰めて、
アスキーアート的に“木の葉”の形を表現する**方式に作り替える。動きは**ほぼ静止＋微かな点滅**。
配色は**左→右の虹グラデーション**。幹・枝（ブラウンの `tree.png`）は現状のまま。

主役は中央の木。可読性・パフォーマンス（長時間8h+稼働）・既存の吸収演出(#44)／マイルストーン・満開(#45)
との両立を保つ。

> 参考画像（クライアント提供）は本環境から参照不可。トーンはレビュー時に調整できるよう
> 色相範囲・文字サイズ・密度・点滅量を定数化しておく。

## 対象ファイル

- `components/vision/CenterTree.tsx` … 樹冠 canvas の描画ロジックを「落下レイン」から「極小文字グリッドの葉」へ作り替え＋虹色化。
- `components/vision/CenterTree.module.scss` … 樹冠（`.canopy`）の発光色を緑→中立（白）系に変更し、虹色が正しく出るようにする（stage 拡大・満開発光含む）。
- `app/globals.scss` … 緑前提の `--color-leaf-glow` を中立グロー（白系）へ調整（`--color-canopy-glow` 等）。

幹・枝（`tree.png`）・木の配置・stage ロジック・`MATRIX_GLYPHS`／`ECO_WORDS` は変更しない。

## 設計（CenterTree.tsx の樹冠 canvas 作り替え）

現状の `clumpFills`（緑グラデのブロブ）と `Column`（落下レイン）を廃し、**極小文字セルのグリッド**に置き換える。
形（葉のシルエット）は既存の `CLUMPS`（葉の塊の円）＋`DRIPS`（垂れ帯）をそのまま流用する。

1. **セルのグリッド生成（初期化時1回）**
   - 小さなセル間隔（例 `CELL≈9px`）・極小フォント（例 `GLYPH_FONT≈8px`）で樹冠バウンディング全体に格子点を作る。
   - 各格子点が葉シルエット内（いずれかの `CLUMPS` 円内、または `DRIPS` 矩形内）にあるセルだけ採用 → 葉の形になる。
   - 各セルに固定値を持たせる：`ch`（`MATRIX_GLYPHS` から1文字）、`hue`（x位置で左→右に算出）、`baseAlpha`（0.55〜0.95でランダム＝葉の質感）、`phase`（点滅位相）。
   - 配列は固定長で使い回し、毎フレームの確保をしない（メモリリーク方針維持）。

2. **虹色（左→右グラデ）**
   - `hue = (x - CROWN_MIN_X) / (CROWN_MAX_X - CROWN_MIN_X) * HUE_SPAN`（例 `HUE_SPAN=300`：赤→紫）。
   - 通常セルは `hsla(hue, ~85%, ~62%, alpha)`。可読性のため彩度・明度を確保。

3. **動き（ほぼ静止＋微かな点滅）= 描画スロットリング**
   - rAF は回すが**通常時は再描画を間引く**（例 ~110ms ごと）。各間引きtickで、
     - ごく一部のセル（数%）の `ch` を差し替え、
     - 一部セルを一瞬明るく（明度↑＝白寄り）して“きらめき”を出す。
   - これで「ほぼ静止＋微かな点滅」を低負荷で実現（毎フレーム全セル描画より軽い）。

4. **吸収演出(#44)の波紋は維持**
   - 既存の `ripples` / `rippleBoost` を流用。波紋通過セルは白く強発光（`hsla` 白）。
   - 波紋中だけ毎フレーム描画（短時間・低頻度）、通常時は間引き描画に戻す。

5. **長時間稼働・アクセシビリティ（既存方針を踏襲）**
   - rAF id を保持しアンマウントで `cancelAnimationFrame`。`visibilitychange` で停止/再開。
   - `prefers-reduced-motion` 時は点滅なしの静止フレームを1枚描く。
   - DPR 反映・`resize` 追従、`vision:absorb` リスナー、`data-canopy` フックは現状どおり維持。

## CSS（CenterTree.module.scss / globals.scss）

- `.canopy` のドロップシャドウ（現状 緑 `--color-leaf-glow`）と stage 別グロー（緑 rgba）、満開 `[data-bloomed]`（緑グロー）を
  **中立の白系グロー**へ変更し、虹色が緑かぶりしないようにする。
- `globals.scss` の緑前提 `--color-leaf-glow` を白系の樹冠グローへ調整（命名も実態に合わせる）。

## マイルストーン／満開との整合（確認のみ）

`lib/animations.ts` のマイルストーン紙吹雪・満開バーストはシアン系の**一時的な別レイヤー**で木自体を再色しない。
虹色樹冠の上に一瞬重なるだけで破綻しない（変更不要）。実機で目視確認する。

## 検証

1. `npm run build` / `npx tsc --noEmit` / `npm run lint` が通ること（`any` 不使用）。
2. `npm run dev` で http://localhost:3000/vision を開き、
   - 樹冠が極小のエコ語録文字で“葉”の形に見えること、
   - 左→右の虹グラデになっていること、
   - ほぼ静止＋微かな点滅で落ち着いて見えること、
   - 幹はブラウンのまま、文字の可読性・木のシルエットが保たれること。
3. /input から宣言送信→ /vision で吸収の波紋が樹冠を白く走ること（#44 維持）。
4. （可能なら）累計をマイルストーン到達させ、演出と虹色が破綻しないこと。
5. devtools で `prefers-reduced-motion` 有効時に点滅が止まり静止描画になること。
